Pick a network

BTX runs against a Bitcoin network. Signet is a free test network — good for learning, no real money. Mainnet is real Bitcoin — every trade costs sats and an initial sync downloads the full blockchain.

Signet Recommended for now
Test network. Trades use test coins with no value. Faucets provide free test BTC. Indexer + ord catch up in under a minute. All BTX features work end-to-end. Pick this if you're trying BTX out.
Mainnet ~3-7 day sync · 700+ GB disk
Real Bitcoin. Trades use real sats. Initial sync downloads the full blockchain — about 700 GB and 3-7 days on a typical connection. The UI will be unavailable until sync completes. Pick this only if you have the disk space and patience and you actually want to trade.

Name your wallet

Your wallet stores your keys locally — BTX never holds your money. Pick a short name to identify it. You can run multiple wallets later in the same Bitcoin Core; "btx" is a sensible default.

Why this is required for mainnet: a fresh mainnet sync is ~700 GB and would take days from scratch. BTX will reuse your existing fully-synced Bitcoin Core install. Point this at the directory that contains blocks/ and chainstate/ — typically %APPDATA%\Bitcoin on Windows, expressed as /mnt/c/Users/<you>/AppData/Roaming/Bitcoin in WSL.
What happens next: BTX creates a Bitcoin Core wallet named btx on the selected network (signet). The wallet keys are stored in your Bitcoin Core data directory — back up that directory if you care about the funds inside.
